# Uber Ride Analytics Dashboard

This project presents an interactive Uber Ride Analytics Dashboard designed to analyze ride-booking data and uncover valuable business insights. The dashboard provides a comprehensive overview of ride performance, booking trends, customer preferences, vehicle types, and trip patterns through interactive visualizations.

## Key Features

* **Ride Overview:** Analyze total bookings, completed rides, and ride performance.
* **Booking Trends:** Track ride bookings across different days and time periods.
* **Vehicle Analysis:** Compare booking performance across different vehicle types.
* **Location Insights:** Identify popular pickup and drop-off locations.
* **Trip Analysis:** Explore trip distances, durations, and booking patterns.
* **Interactive Dashboard:** Use filters and visualizations to explore the data and identify trends.

## Tools & Technologies

* Power BI
* Microsoft Excel
* Data Cleaning and Transformation
* Data Visualization
* DAX (Data Analysis Expressions)

## Project Objective

The objective of this project is to transform raw ride-booking data into meaningful insights that help understand customer behavior, identify booking patterns, and support data-driven business decisions.

This project demonstrates practical skills in data analytics, dashboard development, and business intelligence.
